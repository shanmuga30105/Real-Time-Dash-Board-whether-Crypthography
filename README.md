# Real-Time-Dash-Board-whether-Crypthography
🌦️ Real-Time Dashboard – Weather Monitoring & Cryptography System

📌 Project Overview

The Real-Time Dashboard – Weather Monitoring & Cryptography System is a web-based application developed using HTML, CSS, and JavaScript. It provides real-time weather information for different cities and offers a secure platform for text encryption and decryption.

The project combines weather monitoring and data security features in a single, user-friendly dashboard.

🎯 Objectives

- Display real-time weather information.
- Search weather details using city names.
- Provide secure text encryption and decryption.
- Create a simple and responsive user interface.
- Demonstrate the integration of web technologies and APIs.

🚀 Features

1. Weather Dashboard

- Search weather by city name.
- Display current temperature in Celsius.
- Show weather conditions and icons.
- Display humidity percentage.
- Show wind speed.
- Display feels-like temperature.

2. Cryptography System

- Encrypt text messages.
- Decrypt encrypted messages.
- Password-based AES-256 encryption.
- Copy encrypted results.
- Clear input and output fields.

🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Functionality and interactive operations.
- Open-Meteo API – Real-time weather information.
- AES-GCM – Secure encryption and decryption.
- PBKDF2 – Password-based key generation.

⚙️ Installation and Execution

1. Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder in VS Code.

3. Open "index.html".

4. Right-click and select Open with Live Server.

5. Enter a city name to view weather information.

6. Navigate to the Cryptography section to encrypt or decrypt messages.
